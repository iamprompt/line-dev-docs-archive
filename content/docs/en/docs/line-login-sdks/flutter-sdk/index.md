# :page-title

:markdown-controlsThe LINE SDK for Flutter is a [Flutter](https://flutter.dev/){rel="[\"nofollow\"]"} plugin that lets you access the functions of [LINE SDK for iOS](/docs/line-login-sdks/ios-sdk/) and [LINE SDK for Android](/docs/line-login-sdks/android-sdk/)in Flutter apps with [Dart](https://dart.dev/){rel="[\"nofollow\"]"}.

The plugin helps you integrate LINE Login features in your app. You can redirect users to LINE or a web page where they log in with their LINE credentials.

## GitHub repository

The LINE SDK for Flutter is an open-source project. You'll find the code and README on [GitHub](https://github.com/line/flutter_line_sdk/){rel="[\"nofollow\"]"}.

## API reference

All classes and methods are documented on the [Dart packages](https://pub.dev/documentation/flutter_line_sdk/latest/flutter_line_sdk/){rel="[\"nofollow\"]"} website.
