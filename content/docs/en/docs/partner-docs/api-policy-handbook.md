# :page-title

:markdown-controlsThe LINE API Policy Handbook is a handbook for corporate customers. This handbook is a document related to the [LINE Official Account Terms of Use](https://terms2.line.me/official_account_terms_jp?country=JP&lang=en){rel="[\"nofollow\"]"} and [LINE Official Account API Terms of Use](https://terms2.line.me/official_account_api_terms_jp?lang=ja&country=JP){rel="[\"nofollow\"]"} (only available in Japanese), and is intended to help you better understand and properly use the LINE API.

Note that the content in this handbook is subject to change as new features are added.
