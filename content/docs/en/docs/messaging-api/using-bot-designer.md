title: Development of the LINE Bot Designer has been terminated
type: note

As announced on [January 18, 2022](/news/2022/01/18/development-of-line-bot-designer-has-been-finished/), LINE Bot Designer is no longer maintained. We recommend that you use the [Flex Message Simulator](/flex-simulator/) to create [Flex Message](/reference/messaging-api/#flex-message) prototypes.
::

LINE Bot Designer is a tool for creating LINE Bot prototypes to design your own chatbots easily and quickly. You're not required to have any programming background use this tool.

![LINE Bot Designer](/media/messaging-api/using-bot-designer/bot-designer.webp){className="[\"w-fix-600\"]"}

## Download LINE Bot Designer

LINE Bot Designer is available for free of charge. You only need to log in with your LINE account when you launch the tool. For the user guide, see this :file-link[manual]{file="https://vos.line-scdn.net/line-developers/docs/media/messaging-api/using-bot-designer/bot-designer-user-manual.pdf"} (PDF).

Download LINE Bot Designer from the [download page](/docs/messaging-api/download-bot-designer/).

## Recommended environment

We recommend these environment versions to use LINE Bot Designer:

- Windows 10
- macOS (Sierra or later)
