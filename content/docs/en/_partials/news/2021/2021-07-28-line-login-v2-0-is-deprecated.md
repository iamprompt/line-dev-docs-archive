LINE Login v2.0 is :glossary-tooltip[[deprecated](/glossary/#deprecated)]{glossary-id="deprecated"}.

Although the date is yet to be determined, LINE Login v2.0 is scheduled for :glossary-tooltip[[end-of-life](/glossary/#end-of-life)]{glossary-id="end-of-life"} in the future, so we recommend that you use LINE Login v2.1. Once determined, the end-of-life time and date will be announced here.

There will be a certain grace period between the end-of-life announcement and the actual end-of-life. For more information, see [LINE Login versions](/docs/line-login/overview/#versions).
