We've released LIFF v2.15.0.

In LIFF v2.15.0, the following features have been added.

- [The 2D code reader feature has been added](#liff-scan-code-v2-2021-09-30)
- [The option of automatically executing the `liff.login()` method when initializing LIFF apps in external browsers has been added](#liff-init-auto-login-2021-09-30)

### The 2D code reader feature has been added

The [`liff.scanCodeV2()`](/reference/liff/#scan-code-v2) method, which can launch a 2D code reader within a LIFF app, has been added.

Due to technical problems, [`liff.scanCode()`](/reference/liff/#scan-code) isn't available for use on LINE for iOS version 9.19.0 or later, or on external browsers, but with [`liff.scanCodeV2()`](/reference/liff/#scan-code-v2), you can now launch a 2D code reader even on the newest version of LINE for iOS, and on external browsers.

::admonition
---
title: The operation specification of liff.scanCodeV2()
type: note
---
`liff.scanCodeV2()` internally uses an external library called [jsQR](https://github.com/cozmo/jsQR){rel="[\"nofollow\"]"}.
Therefore, the 2D code reader to be launched when the `liff.scanCodeV2()` method is executed depends on the operation specification of [jsQR](https://github.com/cozmo/jsQR){rel="[\"nofollow\"]"}. Libraries used may be updated or changed without notice.
::

::admonition{title="liff.scanCode() method deprecated" type="note"}
The traditional `liff.scanCode()` method has been :glossary-tooltip[[deprecated](/glossary/#deprecated)]{glossary-id="deprecated"}. We recommend using the `liff.scanCodeV2()` method for implementing a 2D code reader.
::

#### Implementing a 2D code reader with `liff.scanCodeV2()`

Implementing a 2D code reader using `liff.scanCodeV2()` is the same as that of `liff.scanCode()`. Turn on **Scan QR** from the LIFF tab on the [LINE Developers Console](/console/) before following these steps to implement `liff.scanCodeV2()`.

  
###### `liff.scanCodeV2()` sample code:

```javascript
liff.scanCodeV2().then(result => {
  // result = { value: '' }
});
```

::admonition
---
title: 2D code reader support on the LINE MINI App is scheduled for October 7, 2021
type: note
---
Using `liff.scanCodeV2()` to launch a 2D code reader requires turning on **Scan QR** from the LIFF tab of the LINE Login channel on the [LINE Developers Console](/console/). The **Scan QR** setting is scheduled to be added for LINE MINI App channels on **October 7, 2021**. Currently, as of **September 30, 2021**, `liff.scanCodeV2()` isn't available for LINE MINI App channels.

![Scan QR](/media/liff/console-scanqr-en.png){className="[\"border\",\"w-fix-280\"]"}
::

#### The operating environment of the `liff.scanCodeV2()` method

These are the operating environments of the `liff.scanCodeV2()` method and the 2D code reader that is displayed:

- [Operating environments](#operating-environments-of-scan-code-v2)
- [2D code reader](#two-dimensional-code-reader)

##### Operating environments

Due to technical problems, the traditional [`liff.scanCode()`](/reference/liff/#scan-code) method isn't available for use on LINE for iOS version 9.19.0 or later, or on external browsers. The newly added [`liff.scanCodeV2()`](/reference/liff/#scan-code-v2) method, however, is available both on the newest version of LINE for iOS and on external browsers.

| OS            | Version      | LINE app version | External browser |
| ------------- | ------------ | ---------------- | ---------------- |
| iOS           | 11-14.2      | ✅                | ❌                | ❌ | ✅ *1 |
| 14.3 or later | ❌            | ❌                | ✅ *2             | ✅ *1 |
| Android       | All versions | ❌                | ❌                | ✅ *2 | ✅ *1 |
| PC            | All versions | ❌                | ❌                | ❌ | ✅ *1 |

*1 You can only use web browsers that support [WebRTC API](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API){rel="[\"nofollow\"]"}.

*2 Only available when the screen size of the LIFF browser is `Full`. For details, see [Size of the LIFF browser](/docs/liff/overview/#screen-size) in the LIFF documentation.

##### 2D code reader

For the `liff.scanCode()` method, Android and iOS each had different 2D code reader screens, but for the `liff.scanCodeV2()` method, the following same screen is displayed, regardless of OS.

![2D code reader screen](/media/liff/two_dimensional_code_reader_en.png){className="[\"w-fix-480\"]"}

If you launch the 2D code reader, a `Tall` size sub-window will be displayed on the bottom of the `Full` size LIFF app screen. Also, if you click on the ![2D code selection](/media/liff/two-dimensional-code-file-selection.png) icon located at the bottom-right of the screen, you can select a 2D code to be read from a photo.

  
For more information on implementing a 2D code reader using `liff.scanCodeV2()`, see [Opening the 2D code reader](/docs/liff/developing-liff-apps/#opening-two-dimensional-code-reader) in the LIFF documentation.

### The option of automatically executing the `liff.login()` method when initializing LIFF apps in external browsers has been added

The `withLoginOnExternalBrowser` property has been added to the `liff.init()` method. Normally, when you access LIFF application on an :glossary-tooltip[[external browser](/glossary/#external-browser)]{glossary-id="external-browser"}, you need to explicitly go through the login process using the `liff.login()` method. By specifying `true` in the newly added `withLoginOnExternalBrowser` property, you can automatically execute the `liff.login()` method when the LIFF app is initialized.

![Login](/media/liff/liff_autologin_en.png){className="[\"w-fix-640\",\"my-3\"]"}

**Sample code with the `withLoginOnExternalBrowser` property added to the `liff.init()` method:**

```js
liff.init({
  liffId: "123456-abcdef",
  withLoginOnExternalBrowser: true, // Enable automatic login process
}).then(() =>
  // Start to use liff's api
});
```

For more information, see [liff.init()](/reference/liff/#initialize-liff-app) in the LIFF API reference.
