As [announced on 31st May, 2021](/news/2021/05/31/liff-permanent-link-pattern-removed/), **Example code for converting URL generated by "Concatenate" to URL of "Replace (Backward compatibility mode)" specification** has been removed at the end of June 2021.

For more information on the current URL specifications for LIFF apps and LINE MINI Apps, see [Opening LIFF apps](/docs/liff/opening-liff-app/) in the LIFF documentation.
