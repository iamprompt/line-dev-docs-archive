Timeline has been revamped as a video platform and will be called "LINE VOOM" starting November 25, 2021. For more information about LINE VOOM, see [Configuration changes due to renewal](https://timeline-event-info.landpress.line.me/event/timeline_renewal){rel="[\"nofollow\"]"}(Japanese only).

With the release of LINE VOOM, the name on the LINE Developers site has also been changed from Timeline to LINE VOOM. The LINE URL scheme for opening Timeline is still available in LINE VOOM. For more information, see [Using LINE features with the LINE URL scheme](/docs/messaging-api/using-line-url-scheme/).
