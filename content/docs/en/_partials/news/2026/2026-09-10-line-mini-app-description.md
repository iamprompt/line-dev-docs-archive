In Japan, the **Apps** tab in LINE features a section called "Daily top trends". In addition to rankings, this section includes multiple categories such as "Restaurants" and "Games", displaying the names of LINE MINI Apps along with a short description for each app.

Starting September 10, 2026, AI will be used to set categories and generate descriptions for LINE MINI Apps, and these updates will be reflected sequentially.

### Effective date

From September 10, 2026 onward

### Details

Based on the content of "Channel description" entered by developers for each LINE MINI App channel, AI will be used to automatically assign categories and generate descriptions. If a description for the LINE MINI App was already set on or before September 9, 2026, it will be excluded from this AI-generated update.

Only verified MINI Apps are displayed in the "Daily top trends".

### Display example

Here is a display example of "Daily top trends".

![](/media/news/2026/daily-top-trends-en.webp){className="[\"bg-border\",\"w-fix-240\"]"}

1. Category: AI determines and sets the category that the LINE MINI App belongs to.
2. LINE MINI App name: Displays the **Channel name** of the LINE MINI App channel.
3. LINE MINI App description: AI generates descriptions (the maximum character limit is 21 full-width characters for Japanese, or 42 half-width alphanumeric characters).

### Request to developers

Developers don't need to make any additional settings to enable AI description generation and category assignment.

However, descriptions and categories are generated and set based on the content entered in the **Channel description** field under the **Basic settings** tab of the relevant LINE MINI App channel. Therefore, enter the app description specifically and clearly in the **Channel description** field.

For more information, see [Channel description](/docs/line-mini-app/discover/console-guide/#channel-description) in the LINE MINI App documentation.
