The [Flex Message Simulator](/flex-simulator/), a tool that lets you create and preview Messaging API Flex Messages in a browser, has been redesigned.

The main updates are as follows:

- [Changed the layout](#changed-the-layout-20261125)
- [Enabled video playback in the preview area](#enable-video-playback-20261125)
- [Improved recipient setup screen](#easy-to-select-the-recipient-20261125)
- [Other updates](#other-updates-20261125)

### Changed the layout

The layout of each feature has been changed. With the preview area and the property area displayed side by side, it's now easier to see how your changes are reflected.

![](/media/news/2026/flex-message-simulator-new-screen.webp){className="[\"bg-border\"]"}

| Left                                                   | Center                                                 | Right                                                                          |
| ------------------------------------------------------ | ------------------------------------------------------ | ------------------------------------------------------------------------------ |
| Tree view area (edits and displays the data structure) | Preview area (displays the Flex Message being created) | Property area (sets the properties of the item selected in the tree view area) |

- Old design  
![](/media/news/2026/flex-message-simulator-old-screen-en.webp){className="[\"bg-border\"]"}

### Enabled video playback in the preview area

You can now play videos included in Flex Messages in the preview area.

![](/media/news/2026/flex-message-simulator-preview-video.webp){className="[\"bg-border\"]"}

In the UI, you can switch between displaying the video and alternative content configured for a video component to check how each looks. While creating your Flex Message, you can check the alternative content shown in environments that don't support video.

![](/media/news/2026/flex-message-simulator-alt-content.webp){className="[\"w-fix-480\"]"}

### Improved recipient setup screen

To view your Flex Message on the LINE app, click **Send** in the menu bar at the top right of the screen (figure 1). Then, add the Flex Message Simulator LINE Official Account as a friend and register your LINE account as a recipient (figure 2).

![](/media/news/2026/flex-message-simulator-fig1.webp){className="[\"bg-border\"]"} ![](/media/news/2026/flex-message-simulator-fig2.webp){className="[\"w-fix-480\"]"}

With this update, the flow of adding the Flex Message Simulator's LINE Official Account as a friend first and then having a verification code issued has become clearer, making the steps easier to follow.

### Other updates

- This update adds dark mode. Use the icon in the upper-right corner of the screen to switch between light and dark modes.  
![](/media/news/2026/flex-message-simulator-dark-mode.webp)
- New size-switch buttons have been added to the preview area so you can check how the content appears on smartphones with different screen sizes.  
![](/media/news/2026/flex-message-simulator-screen-size-switch.webp){className="[\"w-fix-480\"]"}

We'll continue to improve the quality of our products and developer documentation to make it easier for developers to create services using the LINE Platform.
