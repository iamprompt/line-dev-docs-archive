We have discontinued the feature that displays the Home icons for the Add friend and Like buttons in [LINE Social Plugins](/docs/line-social-plugins/general/overview/).

Previously, users could navigate to the LINE Official Account's LINE VOOM account page via the Home icon, but since LINE VOOM is scheduled to be discontinued, we have ended support for the Home icon.

| Button                                                                                 | Before the change                                                                                                                                                                                                                                    | After the change (current)                                                                                                                                                                                                                                                     |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Add friend button](/docs/line-social-plugins/install-guide/using-add-friend-buttons/) | ![](/media/news/2026/add-friend-home-icon-asis-en.png){className="[\"w-fix-280\"]"}   You could display the Add friend button, the number of friends, and the Home icon.                                                                             | ![](/media/news/2026/add-friend-home-icon-tobe-en.png){className="[\"w-fix-300\"]"}   The option to include the Home icon is no longer selectable when creating a button. In addition, the Home icon is no longer displayed on existing buttons where it was previously shown. |
| [Like button](/docs/line-social-plugins/install-guide/using-like-buttons/)             | ![](/media/news/2026/like-add-friend-home-icon-asis-en.png){className="[\"w-fix-280\"]"}   When the Like button and Add friend button were displayed together, users who had already added your LINE Official Account as a friend saw the Home icon. | ![](/media/news/2026/like-add-friend-home-icon-tobe-en.png){className="[\"w-fix-300\"]"}   The Home icon does not appear, and the Add friend button is always displayed.                                                                                                       |

For more information on the discontinuation of LINE VOOM, see the following notices:

- For Japan: [「LINE VOOM」サービス終了のお知らせ](https://notice.line.me/line/ios/document/notice?documentId=100026857&lang=ja){rel="[\"nofollow\"]"}
- For Taiwan: [LINE VOOM 服務終止通知](https://notice.line.me/line/ios/document/notice?documentId=100027593&lang=zh-Hant){rel="[\"nofollow\"]"}
- For Thailand: [ประกาศยุติการให้บริการ “LINE VOOM” ในประเทศไทย](https://notice.line.me/line/ios/document/notice?documentId=100026413){rel="[\"nofollow\"]"}

In addition, due to this change, we have removed the references to LINE VOOM from the [Usage Guidelines for the LINE Social Plugin](/docs/line-social-plugins/general/guidelines/).

We will continue to work to further improve our service to our customers. Thank you for your understanding.
