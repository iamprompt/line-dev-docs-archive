::admonition{title="Added on September 30, 2026" type="warning"}
LIFF v2.29.2 has been :glossary-tooltip[[deprecated](/glossary/#deprecated)]{glossary-id="deprecated"} because an issue with potential security implications was identified. If you're using LIFF v2.29.2, update to LIFF v2.31.1 or later. For more information, see [LIFF v2.31.1 released](/news/2026/09/30/release-liff-2-31-1/).
::

We've released LIFF v2.29.2.

In LIFF v2.29.2, we've made changes to the internal behavior of the LIFF SDK. There is no change in features.

### How to update to LIFF v2.29.2

If you're using the CDN edge path (`https://static.line-scdn.net/liff/edge/2/sdk.js`), you'll automatically update LIFF to v2.29.2.

If you're using an npm package, you can update to v2.29.2 by executing either `npm install @line/liff@2.29.2` or `yarn add @line/liff@2.29.2`.

For more information on integrating the LIFF SDK, see [Integrating the LIFF SDK with the LIFF app](/docs/liff/developing-liff-apps/#integrating-sdk) in the LIFF documentation.
