The [LINE API Expert](/community/#lae) program in Japan will end when current appointments expire. The [LINE API Platform Evangelist](/community/#platform-evangelist) program in Japan will also end at that time. Beginning in 2027, no new appointments will be made in Japan. Existing appointments won't be renewed.

However, the LINE API Expert programs in Taiwan and Thailand will continue in 2027 and beyond.

### Reflecting on the end of the LINE API Expert program

The LINE API Expert program appoints developers with a deep understanding of LINE APIs. Appointees have advanced technical skills and influence in the community. The program [began in 2017](/news/2017/11/01/line-api-expert-release/). In early 2026, LINE API Platform Evangelist was introduced. It's a role for LINE API Experts. People in this role lead the operation and growth of the community.

The LINE API Expert program is approaching its 10th anniversary. Over the past decade, LINE API Experts appointed in Japan have raised awareness of LINE APIs. They've done so through well over 400 community activities, including meetups and hands-on seminars. These efforts have been a major driving force in expanding the reach of LINE APIs across Japan. They've also provided tremendous support to us as the provider of the LINE Platform.

To everyone who has contributed, we offer our deepest respect and gratitude. We're sincerely grateful for the time we've spent working together.

Although the LINE API Expert program in Japan is ending, we'll continue to improve our services. We'll also continue to improve the quality of the LINE Developers site and developer documentation. Our goal is to make it easier for developers to build services using LINE APIs.

We hope you'll continue to make active use of LINE APIs and that they'll help you create innovative services.
