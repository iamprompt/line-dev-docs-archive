We'd like to inform you about a service outage regarding the LINE Platform. We sincerely apologize for any inconvenience that this may have caused.

## Date and time of outage

July 28, 2026 around 16:45 (UTC+9) (ongoing)

## Cause of the outage

Under investigation

## Impact

- Messaging API
- LINE Login
- LIFF/LINE MINI App
- LINE Developers Console

## Details

These are the main impacts per product:

- [Messaging API](#outage-state-20260728-01)
- [LINE Login](#outage-state-20260728-02)
- [LIFF/LINE MINI App](#outage-state-20260728-03)
- [LINE Developers Console](#outage-state-20260728-04)

### Messaging API

There is an issue where the functions provided by the [Messaging API](/docs/messaging-api/) cannot be used properly.

### LINE Login

There may be instances where adding a LINE Official Account as a friend or unblocking it using the [add friend option](/docs/line-login/link-a-bot/) doesn't work properly.

### LIFF/LINE MINI App

There may be instances where adding a LINE Official Account as a friend or unblocking it using the [add friend option](/docs/line-login/link-a-bot/) or the [`liff.requestFriendship()`](/reference/liff/#request-friendship) method doesn't work properly.

### LINE Developers Console

There may be instances where channel settings cannot be changed properly.

We are still investigating the issue. Details will be provided as they become available.

Please check the [LINE API Status](https://api.line-status.info/incidents/ffzrh28hv6t1){rel="[\"nofollow\"]"} for the latest information.
