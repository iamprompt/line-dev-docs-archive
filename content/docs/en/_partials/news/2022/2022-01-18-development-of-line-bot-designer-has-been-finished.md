We have terminated the development of the [LINE Bot Designer](/services/bot-designer/), which has been used for creating LINE Bot prototypes. As a result, new features added to the Messaging API in the future won't be available on the LINE Bot Designer.

::admonition{title="Creating a Flex Message prototype" type="tip"}
We recommend using the [Flex Message Simulator](/flex-simulator/) to create a [Flex Message](/reference/messaging-api/#flex-message) prototype. The Flex Message Simulator will support new features added to the Flex Message in the future.
::

Although the LINE Bot Designer is likely to be :glossary-tooltip[[deprecated](/glossary/#deprecated)]{glossary-id="deprecated"} in the future, you can still download it from [Download the LINE Bot Designer](/docs/messaging-api/download-bot-designer/).

LINE will continue to improve the quality of its services for its customers. Thank you for your understanding.
