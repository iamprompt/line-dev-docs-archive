We've published "[Getting user IDs](/docs/messaging-api/getting-user-ids/)" in the Messaging API documentation.

When you want to send a message to a specific user using the Messaging API, specify the user ID. In "[Getting user IDs](/docs/messaging-api/getting-user-ids/)", we explain how to get these user IDs.

We'll continue to improve the quality of the LINE Developers site and developer documentation to make it even easier for developers to develop services using the Messaging API.
