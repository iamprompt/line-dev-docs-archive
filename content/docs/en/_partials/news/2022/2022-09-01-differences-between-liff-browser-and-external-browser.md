We've published "[The differences between LIFF browser and external browser](/docs/liff/differences-between-liff-browser-and-external-browser/)" in the LIFF documentation.

The :glossary-tooltip[[LIFF browser](/glossary/#liff-browser)]{glossary-id="liff-browser"} doesn't support some of the web technologies supported by :glossary-tooltip[[external browsers](/glossary/#external-browser)]{glossary-id="external-browser"}. In "[The differences between LIFF browser and external browser](/docs/liff/differences-between-liff-browser-and-external-browser/)", you can find the web technologies that aren't supported by the LIFF browser.

We'll continue to improve the quality of the LINE Developers site and developer documentation to make it even easier for developers to develop apps using our services.
