The [LINE Conversion API](https://data.linebiz.com/solutions/conversion-api){rel="[\"nofollow\"]"} is now available.

Using the LINE Conversion API, it's possible to send user information and event data directly from the advertiser's server to the LINE's server.

For more information about the LINE Conversion API, see [LINE Conversion API](https://data.linebiz.com/solutions/conversion-api){rel="[\"nofollow\"]"} (only available in Japanese) on LINE DATA SOLUTION and [LINE Conversion API development guidelines](https://conversion-api-docs.linebiz.com/en/){rel="[\"nofollow\"]"}.
