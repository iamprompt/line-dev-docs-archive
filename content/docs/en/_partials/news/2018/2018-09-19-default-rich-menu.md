Now you can configure the default rich menu with the Messaging API.

Both default rich menus created using [LINE@ Manager](https://admin-official.line.me){rel="[\"nofollow\"]"} and the Messaging API are supported and can be used at the same time.

For more information on how to use the rich menu features, see the following pages.

- [Using rich menus](/docs/messaging-api/using-rich-menus/)
- [Rich menu](/reference/messaging-api/#rich-menu) in the Messaging API reference
