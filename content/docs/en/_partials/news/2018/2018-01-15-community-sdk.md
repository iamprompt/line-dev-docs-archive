We have released a community SDK section to our [Messaging API SDKs](/docs/messaging-api/line-bot-sdk/) page with Messaging API SDKs developed by our developer community. We currently have a [C# (.NET) SDK](https://github.com/pierre3/LineMessagingApi){rel="[\"nofollow\"]"} and are looking to add more resources.

If you have developed a SDK or library for the Messaging API, see our [Community contribution guidelines](/docs/messaging-api/community-contribution-guideline/) for information on how to submit your project to us for review.
