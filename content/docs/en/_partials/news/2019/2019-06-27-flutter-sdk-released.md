We've released a new [LINE SDK for Flutter](/docs/flutter-sdk/). This SDK is a Flutter plugin that lets you access the functions of LINE SDK for iOS and LINE SDK for Android in your Flutter app with Dart. For details, see these pages:

- [LINE SDK for Flutter](/docs/flutter-sdk/) page on this site
- [flutter_line_sdk](https://github.com/line/flutter_line_sdk/){rel="[\"nofollow\"]"} on GitHub
- [API reference](https://pub.dev/documentation/flutter_line_sdk/latest/flutter_line_sdk/){rel="[\"nofollow\"]"} on Dart packages website

The LINE SDK for Flutter documentation is only available in English, for now.
