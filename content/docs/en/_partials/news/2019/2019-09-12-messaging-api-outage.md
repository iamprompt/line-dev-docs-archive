We'd like to inform you about a service outage regarding the Messaging API. The issue has now been resolved. We apologize for any inconvenience that this may have caused.

### Date and time of outage

Date: September 11, 2019
Time: 17:00 - 18:30 (UTC+9)

Date: September 12, 2019
Time: 13:00 - 13:30 (UTC+9)

### Cause

Server outage due to heavy load.

### Affected services

All Messaging API endpoints ([https://api.line.me/v2/bot/](https://api.line.me/v2/bot/){rel="[\"nofollow\"]"}*).

### Details

The API returned status code 500 for some requests. Also, the "Send reply message" endpoint ([https://api.line.me/v2/bot/message/reply](https://api.line.me/v2/bot/message/reply){rel="[\"nofollow\"]"}) returned error codes in the 400 range, even for correct requests.

LINE will continue to improve the quality of its services to prevent future outages. Thank you for your understanding.
