We released the [LINE SDK 1.0.0 for Unity](/docs/unity-sdk/).

The LINE SDK for Unity is a wrapper for our existing LINE SDKs for [iOS](/docs/ios-sdk/) and [Android](/docs/android-sdk/). This means you can now use the functionality offered by those SDKs in your Unity games.

Read [our guide](/docs/unity-sdk/) to learn more. In addition to the guide, we'll soon release a full reference for the methods available in the SDK.
