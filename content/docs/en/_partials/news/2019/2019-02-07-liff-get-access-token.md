We added the `liff.getAccessToken()` method to the LIFF SDK.

Use the access token to interact with the [Social API](/docs/social-api/overview/) to access user profile data on the LINE Platform.

For more information, see [Getting the user's access token](/docs/liff/developing-liff-apps/#getting-tokens).
