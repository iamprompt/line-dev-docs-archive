Previously, the following Messaging API endpoint didn't allow LINE Official Accounts created in Thailand (TH) to get user activity statistics. Today, we've made it available.

- [Get user activity statistics](/reference/messaging-api/#get-message-event)

This endpoint returns the same data as on the **Insight** tab in the [LINE Official Account manager](https://manager.line.biz){rel="[\"nofollow\"]"}.
