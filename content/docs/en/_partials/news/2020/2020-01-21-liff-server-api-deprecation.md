March 31, 2020 marks the end-of-life date for **LINE Front-end Framework (LIFF) v1 Server API**. On that date, these features will be removed:

- [Server API](/reference/liff-server/)
  - [Adding the LIFF app to a channel](/reference/liff-server/#add-liff-app)
  - [Update LIFF app settings](/reference/liff-server/#update-liff-app)
  - [Get all LIFF apps](/reference/liff-server/#get-all-liff-apps)
  - [Delete LIFF app from a channel](/reference/liff-server/#delete-liff-app)

::admonition{title="Use the latest version of LIFF" type="note"}
As announced on [October 16, 2019](/news/2019/10/16/liff-v2-released/), LIFF v1 will be discontinued.
::

## Use LIFF v2

All discontinued Server API functions can be used in the [LINE Developers Console](/console/). For more information on how to add a LIFF app to a channel, read this:

- [Adding a LIFF app to your channel](/docs/liff/registering-liff-apps/)

You can use other features with the same process.

LINE will continue to improve the quality of its services. Thank you for your understanding.
