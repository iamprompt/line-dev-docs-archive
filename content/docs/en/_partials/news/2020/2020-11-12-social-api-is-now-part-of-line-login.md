Social API will now be treated as a part of LINE Login.

::admonition{title="No change in functionality" type="note"}
There are no changes to the endpoints or functions. You can use it the same as before the merge.
::

See also the new documentation and API reference.

- [LINE Login documentation](/docs/line-login/)
- [LINE Login v2.1 API reference](/reference/line-login/)

- [Managing access tokens (LINE Login v2.0)](/docs/line-login/managing-access-tokens-v2/)
- [Managing users (LINE Login v2.0)](/docs/line-login/managing-users-v2/)
