As announced on [November 11, 2019](/news/2019/11/11/liff-cannot-be-used-with-messaging-api-channels/), due to a function enhancement with LIFF v2, users can no longer add LIFF apps to Messaging API channels.

To find out about restrictions on LIFF apps already added to the Messaging API channel, and how to transition to the LINE Login channel, see the above news article.
