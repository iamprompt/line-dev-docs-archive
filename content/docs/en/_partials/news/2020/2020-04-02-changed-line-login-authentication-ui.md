We've revised some of the design and text to make the consent screen of LINE Login easier to see and use.

### Changes

- To make it easier for users to understand what to do on this screen, we've removed the screen title `Grant permission?` and changed the screen description statement to `This service's provider is requesting the following permissions.`.
- You can show or hide the description of each item by clicking on the ![Arrow icon](/media/line-login/release-note/arrow-icon.png) icon in the `Required permissions` section.
- We've enlarged the `Allow` button to improve visibility.

![Improved LINE Login Consent Screen](/media/line-login/release-note/ui-improvement-en.png){className="[\"w-fix-960\"]"}

The changed consent screen appears in the process of requesting the user to grant permissions to the app. For more information, see [Authorization process](/docs/line-login/integrate-line-login/#authorization-process).
