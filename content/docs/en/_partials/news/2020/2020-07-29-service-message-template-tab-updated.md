The [**Service message template**] tab of the LINE MINI App channel has been updated.

You can select a template and add it to your LINE MINI App channel while viewing the preview of the service message.

![Service message template](/media/line-mini-app/service-message-template-1.png){className="[\"border\",\"w-fix-520\"]"}

You can also enter a JSON object to see the preview or send a test message.

![Send Test Message](/media/line-mini-app/service-message-template-2.png){className="[\"border\",\"w-fix-520\"]"}

For more information, see [Sending service messages](/docs/line-mini-app/develop/service-messages/).
