We [announced that the end-of-life of LINE Front-end Framework (LIFF) server API was scheduled for March 31, 2020](/news/2020/01/21/liff-server-api-deprecation/). Due to feedback received, we will continue to provide the API.

As for LIFF v1, we will announce the discontinuation schedule as soon as it is decided. In the meantime, we recommend that you migrate from v1 to v2 as soon as possible.

| Feature                                              | Schedule before this update                     | Schedule after this update                           |
| ---------------------------------------------------- | ----------------------------------------------- | ---------------------------------------------------- |
| [LIFF v1 Client API](/reference/liff-v1/#client-api) | Scheduled for discontinuation                   | Scheduled for discontinuation (This has not changed) |
| [LIFF v1 Server API](/reference/liff-v1/#server-api) | Scheduled for discontinuation on March 31, 2020 | **Support continues**                                |

::admonition{title="LIFF v1 will still be discontinued" type="note"}
As announced on [October 16, 2019](/news/2019/10/16/liff-v2-released/), LIFF v1 will be discontinued. Use the latest version of LIFF.
::
