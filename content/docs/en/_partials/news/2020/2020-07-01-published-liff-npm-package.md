Until now, to include the LIFF SDK in a LIFF app, it was necessary to [Specify the CDN path](/docs/liff/developing-liff-apps/#integrating-sdk).

Today, we released the LIFF SDK npm package on a trial basis. Now you can use npm and Yarn to install the LIFF SDK.

For more information on the LIFF SDK npm package, see [https://www.npmjs.com/package/@line/liff](https://www.npmjs.com/package/@line/liff){rel="[\"nofollow\"]"}.

The available LIFF SDK versions as an npm package is v2.3.0 or later. The features of future LIFF SDK versions will be announced in [Release Notes](/docs/liff/release-notes/) in the LIFF Documentation.

::admonition{title="npm package trial" type="note"}
The npm package is available on a trial basis. It may be changed or deleted in the future without notice.
::
