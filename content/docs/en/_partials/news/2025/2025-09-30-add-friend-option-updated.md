We've changed the design of the [add friend option](/docs/line-login/link-a-bot/) displayed on the channel consent screen. There are no changes to the feature.

The add friend option is a feature that allows you to display an option for users to add your LINE Official Account as a friend when they log in to an app incorporating the LINE Login (such as a LIFF app or a LINE MINI App).

### Date of change

September 30, 2025

### Changes

The design changes to the add friend option are as follows:

- Added an "Add as friend" section
- Changed the button to a toggle button
- Added a description about adding friends

Screenshots before and after the changes are as follows:

This design change implements the proposal that received the most positive feedback from LINE users, according to A/B test results.

For more information, see [Add a LINE Official Account as a friend when logged in (add friend option)](/docs/line-login/link-a-bot/) in the LINE Login documentation.
