We've officially released the Common Profile Quick-fill feature in the LINE MINI App. Quick-fill is a feature that allows LINE MINI Apps to utilize the information from the Common Profile set up by users in the Account Center. When a user taps **Auto-fill** within a LINE MINI App, the necessary profile information is automatically filled.

![](/media/line-mini-app/quick-fill/quick-fill-3-steps.webp){className="[\"bg-border\",\"w-fix-680\"]"}

This Quick-fill feature was previously available only to specific corporate customers. With this release, you can now use Quick-fill in verified MINI Apps by submitting an [application to use Quick-fill](/docs/line-mini-app/quick-fill/overview/#step-one-quick-fill-application).

Additionally, as part of this release, the Quick-fill documentation has been moved from the options for corporate customers documentation to the LINE MINI App documentation. For more information about Quick-fill, see [Overview of Common Profile Quick-fill](/docs/line-mini-app/quick-fill/overview/) in the LINE MINI App documentation.
