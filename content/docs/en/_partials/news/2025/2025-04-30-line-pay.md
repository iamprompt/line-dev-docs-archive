As of April 30, 2025, the LINE Pay service in Japan has been terminated. As a result, we've discontinued providing the following documentation and references on the LINE Developers site:

- LINE Pay Online documentation
- LINE Pay Online API reference
- LINE Pay Offline documentation
- LINE Pay Offline API reference

For more information about the LINE Pay service termination in Japan, see [Notice of the LINE Pay service termination](https://line-pay-info.landpress.line.me/payment-info/){rel="[\"nofollow\"]"} (only available in Japanese).

The LINE Pay services in Taiwan and Thailand will continue to be available. When developing services using LINE Pay in these regions, see the documentation and references on the [LINE Pay Developers](https://developers-pay.line.me/){rel="[\"nofollow\"]"}.

- [Online payment documentation](https://developers-pay.line.me/online){rel="[\"nofollow\"]"}
- [Online API reference](https://developers-pay.line.me/online-api){rel="[\"nofollow\"]"}
- [Offline payment documentation](https://developers-pay.line.me/offline){rel="[\"nofollow\"]"}
- [Offline API reference](https://developers-pay.line.me/offline-api){rel="[\"nofollow\"]"}

We'll continue to work to further improve its service to our customers. Thank you for your understanding.
