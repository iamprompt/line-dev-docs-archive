On LINE version 14.3.0, **Add to Home Screen** has been added to the [action button](/docs/line-mini-app/discover/builtin-features/#action-button) options in the LINE MINI App.

Tapping **Add to Home Screen** will display the Add Shortcut screen like using the [`liff.createShortcutOnHomeScreen()`](/reference/liff/#create-shortcut-on-home-screen) method.

With this, in all LINE MINI Apps, users can now add a shortcut to a LINE MINI App to the home screen of the user's device.

For more information about shortcuts to your LINE MINI App, see [Add a shortcut to your LINE MINI App to the home screen of the user's device](/docs/line-mini-app/develop/add-to-home-screen/) in the LINE MINI App documentation.
