We have released `imageAspectRatio`, `imageSize`, and `imageBackgroundColor` fields for [Buttons](/docs/messaging-api/message-types/#buttons-template) and [Carousel](/docs/messaging-api/message-types/#carousel-template) template messages. Using these fields, you can configure the aspect ratio, size, and background color for images used in template messages. For more information, see the reference documentation below.

- [Buttons template message](/reference/messaging-api/#buttons)
- [Carousel template message](/reference/messaging-api/#carousel)
