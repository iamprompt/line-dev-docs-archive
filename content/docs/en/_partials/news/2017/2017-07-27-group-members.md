We’ve released resources for the Messaging API which lets you get the user IDs and LINE user profiles of the members of a group or room that your bot is in.

For more information on how to use these resources, see the API reference items below.

- [Get group member profile](/reference/messaging-api/#get-group-member-profile), [Get room member profile](/reference/messaging-api/#get-room-member-profile)
- [Get group member IDs](/reference/messaging-api/#get-group-member-user-ids), [Get room member IDs](/reference/messaging-api/#get-room-member-user-ids) (Note: This resource is only available for LINE@ Approved accounts and LINE Official Accounts.)
