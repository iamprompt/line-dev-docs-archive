We've increased the number of column objects that you can include in your [carousel](/docs/messaging-api/message-types/#carousel-template) and [image carousel](/docs/messaging-api/message-types/#image-carousel-template) template messages from 5 to 10 objects.

For more information, see the updated reference documentation below.

- [Carousel](/reference/messaging-api/#carousel)
- [Image carousel](/reference/messaging-api/#image-carousel)
