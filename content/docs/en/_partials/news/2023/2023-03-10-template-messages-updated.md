:glossary-tooltip[[Template messages](/glossary/#template-message)]{glossary-id="template-message"} sent by [`liff.sendMessages()`](/reference/liff/#send-messages) and [`liff.shareTargetPicker()`](/reference/liff/#share-target-picker) in LIFF are now available for the desktop version of LINE (macOS and Windows).

Messaging API :glossary-tooltip[[template messages](/glossary/#template-message)]{glossary-id="template-message"} have been available for the desktop version of LINE from September 21, 2022, but it wasn't supported for template messages sent by LIFF method.

For more information about the changes and versions covered by this support, see the news on September 21, 2022, [Messaging API template messages are now available for the desktop version of LINE](/news/2022/09/21/template-messages-updated/).

These changes apply only to the template messages sent after the specification change. The template messages that have already been sent won't be affected.
