::admonition{title="Added on October 20, 2026" type="warning"}
To ensure user safety, we plan to restrict the use of older versions of the LIFF SDK (v2.20.0 through v2.31.0) around November 24, 2026. If you are using LIFF v2.23.0, update to LIFF v2.31.1 or later immediately. For more information, see the news from October 20, 2026, [Overview of the LIFF SDK vulnerability in LIFF/LINE MINI App and restrictions on using older versions](/news/2026/10/20/liff-sdk-issue/).
::

::admonition{title="Added on September 30, 2026" type="warning"}
LIFF v2.23.0 has been :glossary-tooltip[[deprecated](/glossary/#deprecated)]{glossary-id="deprecated"} because an issue with potential security implications was identified. If you're using LIFF v2.23.0, update to LIFF v2.31.1 or later. For more information, see [LIFF v2.31.1 released](/news/2026/09/30/release-liff-2-31-1/).
::

We've released LIFF v2.23.0.

In LIFF v2.23.0, we've made changes to the internal behavior of the LIFF SDK. There is no change in features.

### How to update to LIFF v2.23.0

If you're using the CDN edge path (`https://static.line-scdn.net/liff/edge/2/sdk.js`), you'll automatically update LIFF to v2.23.0.

If you're using an npm package, you can update to v2.23.0 by executing either `npm install @line/liff@2.23.0` or `yarn add @line/liff@2.23.0`.

For more information on integrating the LIFF SDK, see [Integrating the LIFF SDK with the LIFF app](/docs/liff/developing-liff-apps/#integrating-sdk) in the LIFF documentation.
