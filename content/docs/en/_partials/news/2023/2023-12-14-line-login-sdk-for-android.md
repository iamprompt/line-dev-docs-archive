We've released [LINE SDK for Android](/docs/line-login-sdks/android-sdk/overview/) v5.10.0. In this release, we've improved the method of generating and storing secret keys used for encryption and decryption of access tokens, etc. In addition, the use of insecure cryptographic methods has been restricted in order to strengthen the protection of user privacy.

As a result of these changes, users who have already logged in to an application that uses LINE Login will be prompted to log in again when LINE SDK for Android is upgraded to this version.

Release notes for LINE SDK for Android are available on the GitHub repository. For more information, see [Release 5.10.0](https://github.com/line/line-sdk-android/releases/tag/v5.10.0){rel="[\"nofollow\"]"} in [Releases](https://github.com/line/line-sdk-android/releases){rel="[\"nofollow\"]"}.
