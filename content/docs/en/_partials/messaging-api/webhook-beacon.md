### Beacon event

::reference-with-code
  :::reference-content
  Event object for when a user enters the range of a [LINE Beacon](/docs/messaging-api/using-beacons/). You can reply to beacon events.

#### Beacon event types

| beacon.type | Description                                                                                                                |
| ----------- | -------------------------------------------------------------------------------------------------------------------------- |
| `enter`     | Entered beacon's reception range.                                                                                          |
| `banner`    | Tapped [beacon banner](/docs/messaging-api/using-beacons/#beacon-banner).                                                  |
| `stay`      | A user is within the range of the beacon's reception.   This event is sent repeatedly at a minimum interval of 10 seconds. |

::admonition{title="Registration has been suspended in Japan" type="note"}
As of January 2021, we are no longer accepting new applications for `banner` and `stay` events in Japan, while other regions except Japan still accept new application.
::
