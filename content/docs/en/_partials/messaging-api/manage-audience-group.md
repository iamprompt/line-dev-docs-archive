Audiences can also be created using [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}. To learn more, see [Audience](https://www.lycbiz.com/jp/manual/OfficialAccountManager/messages-audience/){rel="[\"nofollow\"]"} in LINE for Business.

| Audience                                     | How to create                                                                                                                                                                                                                                   |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| An audience used for uploading user IDs      | - [Messaging API](#create-upload-audience-group) - [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"} - [LINE Points Ads](https://www.lycbiz.com/jp/service/line-point-ad/){rel="[\"nofollow\"]"} (Japanese only) |
| Message click audience                       | - [Messaging API](#create-click-audience-group) - [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}                                                                                                              |
| Message impression audience                  | - [Messaging API](#create-imp-audience-group) - [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                |
| Chat tag audience                            | [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                |
| Friend path audience                         | [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                |
| Reservation audience                         | [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                |
| Rich menu impression audience                | [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                |
| Rich menu click audience                     | [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                |
| Web traffic audience (LINE Tag)              | - [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"} - [LINE Ads](https://admanager.line.biz/){rel="[\"nofollow\"]"}                                                                                              |
| Web traffic audience (Tracking Tag)          | [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                |
| App event audience                           | [LINE Ads](https://admanager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                                   |
| Video view audience                          | [LINE Ads](https://admanager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                                   |
| Image click audience                         | [LINE Ads](https://admanager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                                   |
| LINE Beacon Network ad impression audience * | [LINE Ads](https://admanager.line.biz/){rel="[\"nofollow\"]"}                                                                                                                                                                                   |

* LINE Beacon Network ad impression audience is only available for LINE Official Accounts created by users in Taiwan.

::admonition{title="Note" type="note"}
- Only Japanese (JP), Thai (TH), and Taiwanese (TW) users with LINE Official Accounts can create audiences.
- You can't create the following types of audiences with the Messaging API:

  - Chat tag audience
  - Friend path audience
  - Reservation audience
  - Rich menu impression audience
  - Rich menu click audience
  - Web traffic audience (LINE Tag)
  - Web traffic audience (Tracking Tag)
  - App event audience
  - Video view audience
  - Image click audience
  - LINE Beacon Network ad impression audience
::
