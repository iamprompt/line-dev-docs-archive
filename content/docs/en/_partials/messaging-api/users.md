## Users

::reference-with-code
  :::reference-content
  You can get information of users who have added your LINE Official Account as a friend.

    ::::admonition{title="Accessing your own user ID" type="note"}
    You can access your user ID under the **Basic settings** tab of your channel on the [LINE Developers Console](/console/). For more information on permissions per role in the LINE Developers Console, see [Channel roles](/docs/line-developers-console/managing-roles/#roles-for-channel) in [Managing roles](/docs/line-developers-console/managing-roles/). There is no API available for retrieving your own user ID.
