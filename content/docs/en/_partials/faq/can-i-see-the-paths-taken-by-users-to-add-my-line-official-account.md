You can't use the Messaging API to see how a specific user added your LINE Official Account as a friend.

You can see the friend adding paths statistics, without identifying individual users, in the [LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}. For more information, see [Insight analytics - Friends](https://www.lycbiz.com/jp/manual/OfficialAccountManager/insight_friends/){rel="[\"nofollow\"]"} (only available in Japanese) in LINE for Business.
