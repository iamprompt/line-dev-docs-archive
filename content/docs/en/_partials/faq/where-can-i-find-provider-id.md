You can find your Provider ID on the [LINE Developers Console](/console/).

- If you have Provider Admin role:  
From the [LINE Developers Console](/console/), select provider and then click **Settings**. You can find your Provider ID under **Provider settings**.  
![Provider ID Admin](/media/faq/provider_2_en.png){className="[\"border\",\"w-fix-720\"]"}
- If you don't have Provider Admin role:  
From the [LINE Developers Console](/console/), select provider. From the page displayed, you will see your Provider ID in the segment after `/provider/` in the URL.  
![Provider ID URL](/media/faq/provider_1_fix_en.png){className="[\"border\",\"w-fix-720\"]"}
