For the LINE Share button only, you can resize the button using a custom icon. For more information about how to install a button using a custom icon, see [Using custom icons](/docs/line-social-plugins/install-guide/using-line-share-buttons/#using-custom-icons). Otherwise, Like buttons and Add friend buttons don't support resizing.
