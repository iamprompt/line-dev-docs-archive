You can find your user ID in the **Your user ID** of the **Basic settings** tab of the channel in the [LINE Developers Console](/console/). For more information, see [Developer gets their own user ID](/docs/messaging-api/getting-user-ids/#get-own-user-id) in the Messaging API documentation.
