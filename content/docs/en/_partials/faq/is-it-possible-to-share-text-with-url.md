When installing the Share button using a custom icon, you can have the URL and text shared together. For more information about how to install a button using a custom icon, see [Using custom icons](/docs/line-social-plugins/install-guide/using-line-share-buttons/#using-custom-icons). When using the official LINE icon, text sharing is not supported.
