To report a problem encountered on the LINE Platform or make a request for improvement, contact us using the help center's [Inquiry form](https://contact-cc.line.me/serviceId/11556){rel="[\"nofollow\"]"}. Note that we may not be able to respond to all inquiries.

If you need technical support, see [How do I contact technical support for inquiring about LINE APIs?](/faq/#i-need-technical-support) in the FAQ.
