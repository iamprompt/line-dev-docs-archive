Once you've linked your LINE Official Account to a Messaging API channel, you can't un-link your LINE Official Account from the Messaging API channel.

If you want to continue using your LINE Official Account linked to the Messaging API channel, but want to stop using the Messaging API, see [Stop using the Messaging API](/docs/messaging-api/stop-using-messaging-api/) in the Messaging API documentation.
