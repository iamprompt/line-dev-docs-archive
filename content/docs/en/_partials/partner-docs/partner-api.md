:toc## Common specifications

### Status codes

For more information, see [Status codes](/reference/messaging-api/#status-codes) in the Messaging API reference.

### Response headers

The following HTTP headers are included in Options for corporate customers API responses:

| Response header   | Description                                   |
| ----------------- | --------------------------------------------- |
| x-line-request-id | Request ID. An ID is issued for each request. |
