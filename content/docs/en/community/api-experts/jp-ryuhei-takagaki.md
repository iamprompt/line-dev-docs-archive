クラスメソッド株式会社 リテールアプリ共創部

1999年岐阜県生まれ。大阪大学卒業後、2024年にクラスメソッド株式会社に入社。在学中の2年間はアパレルテック企業にてLIFFアプリの開発に従事。現在クラスメソッド株式会社では小売業界向けのLIFFアプリやLINEミニアプリの新規開発・運用保守を担当している。

技術面では、ReactやNext.jsを活用したモダンフロントエンド開発を得意とし、AWSなどのクラウドサービスを駆使したサーバーレスバックエンド開発にも精通。フルスタックエンジニアとして幅広い技術領域をカバーしている。

現在は、LINEミニアプリ開発のためのアセットと生成AIを組み合わせることで、顧客により迅速で高品質なプロダクト提供を実現するプロジェクトに従事。
