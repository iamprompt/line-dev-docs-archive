C#やAzureなどMicrosoft関連技術が好きなエンジニア。LINE APIとの組み合わせで何かおもしろいことができないか日々模索しています。
本職は人材派遣会社のテクニカルトレーナー兼開発者。さまざまなIT技術の研修やハンズオンの企画・講師を務める傍ら、クラウドを活用したシステムやLINE Botの開発を担当しています。

Microsoft Azureのサーバーレス技術（Azure Functions, Logic Apps など）とLINE Messaging APIや Clovaスキルとの組み合わせを中心に、開発したものをブログやGitHubに公開したり開発コンテストに出したりしています。また、LINE APIのC#コミュニティSDKの開発にも携わっています。
