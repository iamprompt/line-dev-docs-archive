# 商標について

本サイトに掲載されているサードパーティの商標は、それぞれの所有者に帰属します。

Apache®、[Apache Maven、およびMaven™](https://maven.apache.org/){rel="[\"nofollow\"]"}は、[Apache Software Foundation](https://www.apache.org/){rel="[\"nofollow\"]"}の米国および/またはその他の国における商標または登録商標です。️

Keychain、macOS、Objective-C、Safari、およびXcodeは、Apple Inc.の米国およびその他の国で登録された商標です。Swiftは、Apple Inc.の商標です。App Storeは、Apple Inc.のサービスマークです。

Bluetooth®のワードマークは、Bluetooth SIG, Inc.が所有する登録商標であり、LINEヤフー株式会社はこのマークをライセンスに基づいて使用しています。その他の商標およびトレードネームは、それぞれの所有者に帰属します。

IOS®は、Cisco Systems, Inc.および/またはその関連会社の米国および他の特定の国における登録商標です。

QRコードは、株式会社デンソーウェーブの日本およびその他の国における登録商標です。

Git™は、Git Projectの運営企業であるSoftware Freedom Conservancy, Inc.の米国および/またはその他の国における商標です。

GitHubおよびElectronは、GitHub, Inc.の米国および/またはその他の国における商標または登録商標です。

Google PlayおよびAndroidはGoogle LLCの商標です。

Linux®は、Linus Torvaldsの米国およびその他の国における登録商標です。

Windowsは、Microsoft Corporationの米国および/またはその他の国における商標または登録商標です。

Node.jsはJoyent, Inc.の商標であり、その許可を得て使用されています。LINEヤフー株式会社はJoyentの推薦を受けておらず、また、Joyentと提携していません。

OpenID®は、OpenID Foundationの（多くの国で登録済みの）商標です。

OracleおよびJavaは、Oracle Corporationおよびその子会社、関連会社の登録商標です。文中の社名、商品名等は各社の商標または登録商標である場合があります。

Perlは、Perl Foundationの商標または登録商標です。

Python®は、Python Software Foundationの商標または登録商標です。

Redis™は、Redis Labs Ltd.の米国およびその他の国における商標です。

Herokuは、Salesforce.com, Inc.の登録商標です。

Netlifyは、Netlify, Inc.の米国における商標または登録商標です。
