### レスポンスヘッダー

LINEログインAPIのレスポンスには、以下のHTTPヘッダーが含まれます。

| レスポンスヘッダー         | 説明                          |
| ----------------- | --------------------------- |
| x-line-request-id | リクエストID。各リクエストごとに発行されるIDです。 |
