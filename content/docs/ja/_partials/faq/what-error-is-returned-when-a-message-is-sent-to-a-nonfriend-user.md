LINE公式アカウントをブロックしているユーザー、またはアカウントを削除したユーザーを指定してメッセージを送信しても、エラーは発生せず、レスポンスとしてはステータスコード200が返ります。

なお、この場合、ユーザーにメッセージは届きません。
