既存のLINE公式アカウントでMessaging APIを利用するには、[LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}でMessaging APIの利用を有効にします。

詳しくは、『Messaging APIドキュメント』の「[LINE公式アカウントでMessaging APIを有効にする](/docs/messaging-api/getting-started/#using-oa-manager)」を参照してください。
