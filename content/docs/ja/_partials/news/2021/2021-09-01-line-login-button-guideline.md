[LINEアプリアイコンのデザイン](https://line.me/ja/logo){rel="[\"nofollow\"]"}変更に伴い、[LINEログインボタンのデザインガイドライン](/docs/line-login/login-button/)を更新しました。

| 種類       | 変更前                                                                                                              |                                                 | 変更後                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 基本色      | ![古いLINEログインボタン基本色](/media/line-login/login-button/old-login-button-base.png){className="[\"w-fix-240\"]"}       | ![矢印](/media/line-login/login-button/arrow.png) | ![新しいLINEログインボタン基本色](/media/line-login/login-button/new-login-button-base.png){className="[\"w-fix-240\"]"}       |
| マウスオーバー  | ![古いLINEログインボタンマウスオーバー](/media/line-login/login-button/old-login-button-hover.png){className="[\"w-fix-240\"]"}  | ![矢印](/media/line-login/login-button/arrow.png) | ![新しいLINEログインボタンマウスオーバー](/media/line-login/login-button/new-login-button-hover.png){className="[\"w-fix-240\"]"}  |
| タップ/クリック | ![古いLINEログインボタンタップ/クリック](/media/line-login/login-button/old-login-button-press.png){className="[\"w-fix-240\"]"} | ![矢印](/media/line-login/login-button/arrow.png) | ![新しいLINEログインボタンタップ/クリック](/media/line-login/login-button/new-login-button-press.png){className="[\"w-fix-240\"]"} |
| 無効       | ![古いLINEログインボタン無効](/media/line-login/login-button/old-login-button-disabled.png){className="[\"w-fix-240\"]"}    | ![矢印](/media/line-login/login-button/arrow.png) | ![新しいLINEログインボタン無効](/media/line-login/login-button/new-login-button-disabled.png){className="[\"w-fix-240\"]"}    |

既存のLINEログインボタンが古い場合や、新規でLINEログインボタンを導入する場合は、『LINEログインドキュメント』の「[LINEログインボタン デザインガイドライン](/docs/line-login/login-button/)」を参照して、新しいLINEログインボタンのデザインを利用してください。
