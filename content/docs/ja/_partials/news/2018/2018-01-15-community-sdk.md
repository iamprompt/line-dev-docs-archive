「[LINE Messaging API SDK](/docs/messaging-api/line-bot-sdk/)」ページにコミュニティSDKのセクションが追加されました。このセクションには、LINEの開発者コミュニティによって開発されるLINE Messaging API SDKを記載していきます。現在は[C#（.NET）SDK](https://github.com/pierre3/LineMessagingApi){rel="[\"nofollow\"]"}のみですが、さらに多くのリソースを追加していく予定です。

Messaging API向けのSDKやライブラリを開発し、コミュニティで共有したい方は、プロジェクトを提出してLINEによるレビューを受ける方法について「[コミュニティ貢献ガイドライン](/docs/messaging-api/community-contribution-guideline/)」を参照してください。
