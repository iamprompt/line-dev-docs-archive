Messaging APIで作成したオーディエンスを、[LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}のステップ配信で使えるようになりました。

[LINE Official Account Manager](https://manager.line.biz/){rel="[\"nofollow\"]"}のステップ配信は、友だち追加日からの経過日数や設定した条件に応じて、複数のメッセージを自動で配信できる機能です。このステップ配信において、配信対象の条件としてMessaging APIで作成したオーディエンスを利用できるようになりました。

![ステップ配信](/media/news/2023/step-messages-ja.png){className="[\"w-fix-480\"]"}

詳しくは、『LINE for Business』の「[ステップ配信](https://www.linebiz.com/jp/manual/OfficialAccountManager/step-message/){rel="[\"nofollow\"]"}」を参照してください。

Messaging APIで作成できるオーディエンスについて詳しくは、『Messaging APIドキュメント』の「[オーディエンスを作成する](/docs/messaging-api/using-audience/#create-audience)」を参照してください。
