LINE広告 レポートAPIの利用方法を紹介する[LINE Ads API documentation](https://ads.line.me/public-docs/){rel="[\"nofollow\"]"}（英語）を公開しました。

::admonition{title="LINE広告 レポートAPIを利用するには申請が必要です" type="note"}
LINE広告 レポートAPIは、所定の申請等を行った法人ユーザーのみがご利用いただけます。自社のLINE広告アカウントでご利用になりたいお客様は、[LINE広告 レポートAPI お申込フォーム](https://feedback.line.me/enquete/public/14293-MPpjqJAs){rel="[\"nofollow\"]"}より申請をお願いいたします。
::
