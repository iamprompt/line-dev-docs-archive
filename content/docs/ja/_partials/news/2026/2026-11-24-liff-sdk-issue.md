2026年10月20日に公開した「[【更新】LIFF/LINEミニアプリにおけるLIFF SDKの脆弱性の概要および旧バージョンの利用制限について](/news/2026/10/20/liff-sdk-issue/)」でお知らせしましたとおり、ユーザーの安全を確保するため、脆弱性が確認されているLIFF SDKの旧バージョン（v2.20.0 〜 v2.31.0）の利用制限を実施いたしました。

### 利用制限の実施状況およびスケジュール

以下のスケジュールのとおり、該当する旧バージョン（v2.20.0 〜 v2.31.0）に対する利用制限を順次実施しています。

#### 2026年11月24日（実施済み）

外部ブラウザおよびLINE内ブラウザからの[`liff.login()`](/reference/liff/#login)メソッド実行時において、該当するLIFF SDKの旧バージョンからのアクセスを制限しました。これにより、該当するバージョンでは`liff.login()`メソッドの実行が失敗するため、LIFF/LINEミニアプリが利用できなくなる可能性があります。

#### 2026年11月25日（実施予定）

外部ブラウザおよびLINE内ブラウザにおいて、該当するLIFF SDKの旧バージョンへのCDN固定パスを利用したアクセスには、ステータスコード`403`のエラーを返すようになります。これにより、`<script>`タグで対象のLIFF SDKを読み込む際にエラーが発生します。

### 引き続きアップデートをお願いします

本対応は、修正版への移行を促進し、脆弱性を悪用されるリスクを低減することを目的としています。

当社による利用制限だけでは、脆弱性のリスクを完全には解消できません。特にnpmパッケージを利用している場合はCDN側の制限が適用されないため、引き続きLIFF SDK v2.31.1以降へのアップデートが必須となります。

該当するバージョンを利用している場合は、速やかにLIFF v2.31.1以降へアップデートしてください。

### LIFF SDK v2.31.1以降へのアップデート方法

LIFF SDKの組み込み方法によって、必要な対応が異なります。ここでは、現在の最新版である[LIFF v2.32.0](/news/2026/11/09/release-liff-2-32-0/)にアップデートする方法を示します。

::admonition{title="最新バージョンを確認してください" type="tip"}
この記事で案内しているLIFF SDKのバージョン（v2.32.0）は記事公開時点のものです。最新のバージョンについて詳しくは、『LIFFドキュメント』の「[現在のバージョン](/docs/liff/release-notes/#current-version)」を参照してください。
::

- [CDNエッジパスを利用している場合](#cdn-edge-path-20261124)
- [CDN固定パスを利用している場合](#cdn-fixed-path-20261124)
- [npmパッケージを利用している場合](#npm-package-20261124)

#### CDNエッジパスを利用している場合

CDNエッジパスを利用している場合は、自動でv2.32.0にアップデートされています。追加の対応は不要です。

```html
<script charset="utf-8" src="https://static.line-scdn.net/liff/edge/2/sdk.js"></script>
```

#### CDN固定パスを利用している場合

CDN固定パスを利用している場合は、読み込むバージョンをv2.32.0に変更してください。

```html
<script charset="utf-8" src="https://static.line-scdn.net/liff/edge/versions/2.32.0/sdk.js"></script>
```

#### npmパッケージを利用している場合

npmパッケージを利用している場合は、`@line/liff`をv2.32.0にアップデートしてください。

```sh
npm install @line/liff@2.32.0
```
