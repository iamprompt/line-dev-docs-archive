2026年9月30日に公開した「[LIFF v2.31.1をリリースしました](/news/2026/09/30/release-liff-2-31-1/)」に関連して、LIFF/LINEミニアプリにおける修正されたセキュリティ上の脆弱性の概要と、それに伴うLIFF SDKの旧バージョンの利用制限についてお知らせします。

::admonition{title="速やかにLIFF v2.31.1以降にアップデートしてください" type="warning"}
ユーザーの安全を確保するため、2026年11月24日頃にLIFF SDKの旧バージョン（v2.20.0 〜 v2.31.0）の利用制限を実施する予定です。該当するバージョンを利用している場合は、速やかにLIFF v2.31.1以降にアップデートしてください。
::

### 脆弱性の概要

LIFF v2.20.0 〜 v2.31.0において、クロスサイトスクリプティング（XSS）の脆弱性が確認されました。本脆弱性は、当社の脆弱性報告窓口を通じて外部のセキュリティ研究者より報告されたものです。

- CVE: [CVE-2026-112148](https://www.cve.org/CVERecord?id=CVE-2026-112148){rel="[\"nofollow\"]"}
- GitHub Advisory: [CVE-2026-112148](https://github.com/line/liff/security/advisories/GHSA-wppr-qmp4-w627){rel="[\"nofollow\"]"}

特定の条件において、不正なURLから:glossary-tooltip[[外部ブラウザ](/glossary/#external-browser)]{glossary-id="external-browser"}でLIFF/LINEミニアプリを開いた際、LIFF/LINEミニアプリのドメイン上で任意のJavaScriptが実行される可能性があります。これにより、アクセストークン等の認証情報や画面上の情報が不正に取得されるおそれがあります。

### 影響範囲

LIFF SDKの旧バージョン（v2.20.0 〜 v2.31.0）を使用している以下のアプリが対象となります。

- LIFFアプリ
- LINEミニアプリ

### 本脆弱性に関する調査結果

当社にて調査を行った結果、現時点で本脆弱性を悪用した攻撃の成立、および実データの漏えいや不正利用の被害は確認されておりません。

しかしながら、すべての環境における影響がないことを完全に保証するものではなく、また脆弱性の情報が公開されていることから、今後悪用されるおそれがあります。被害を未然に防ぐため、該当するバージョンを利用している場合は、速やかなアップデートをお願いします。

### 旧バージョンの利用制限について

被害を未然に防ぐため、以下のスケジュールでLIFF SDKの旧バージョン（v2.20.0 〜 v2.31.0）の利用を制限する予定です。

#### 実施予定日

2026年11月24日（火）頃

なお、利用制限の実施日は予告なく前倒しすることがあります。

#### 制限による影響

利用制限後は、該当する旧バージョンを利用するLIFF/LINEミニアプリを外部ブラウザで開いた際、以下のような影響が生じる可能性があります。

- LINEログインやその他のLIFFの機能が利用できなくなる
- LIFF/LINEミニアプリが正常に動作しなくなる

なお、当社による利用制限だけでは、脆弱性のリスクを完全には解消できません。利用制限の実施日を待たずに、速やかにLIFF v2.31.1以降にアップデートしてください。

### LIFF v2.31.1以降へのアップデート方法

LIFF SDKの組み込み方法によって、必要な対応が異なります。ここでは、現在の最新版であるLIFF v2.31.2にアップデートする方法を示します。

- [CDNエッジパスを利用している場合](#cdn-edge-path-20261020)
- [CDN固定パスを利用している場合](#cdn-fixed-path-20261020)
- [npmパッケージを利用している場合](#npm-package-20261020)

#### CDNエッジパスを利用している場合

CDNエッジパスを利用している場合は、自動でv2.31.2にアップデートされています。追加の対応は不要です。

```html
<script charset="utf-8" src="https://static.line-scdn.net/liff/edge/2/sdk.js"></script>
```

#### CDN固定パスを利用している場合

CDN固定パスを利用している場合は、読み込むバージョンをv2.31.2に変更してください。

```html
<script charset="utf-8" src="https://static.line-scdn.net/liff/edge/versions/2.31.2/sdk.js"></script>
```

#### npmパッケージを利用している場合

npmパッケージを利用している場合は、`@line/liff`をv2.31.2にアップデートしてください。

```sh
npm install @line/liff@2.31.2
```
