LINEバージョン26.18.0より、日本のユーザーを対象に、認証済ミニアプリを検索した際に表示される内容が変更されます。

対象となるのは、下記のタブで認証済ミニアプリを検索した場合です。

- ［**トーク**］タブ
- ［**ミニアプリ**］タブ

### 対象バージョン

LINEバージョン26.18.0以降（2026年11月初旬リリース予定）

### 実施内容

従来は、LINEミニアプリを検索すると、検索結果に「LINEミニアプリ名」のみが表示されていました。

仕様変更後は、検索結果として次の項目が表示されます。

| 項目名          | 説明                            |
| ------------ | ----------------------------- |
| LINEミニアプリ名   | LINEミニアプリの名前                  |
| カテゴリ         | LINEミニアプリが属するカテゴリ（例：飲食店、ゲーム）  |
| LINEミニアプリの説明 | LINEミニアプリの説明文                 |
| サービスバッジ      | LINEミニアプリの主な機能（例：モバイル注文、会員登録） |

なお、LINEミニアプリ名には、LINEミニアプリチャネルの［**チャネル名**］が表示されます。それ以外の項目については、LINEミニアプリチャネルの［**チャネル基本設定**］タブ > ［**チャネル説明**］の項目に入力された内容等に基づいて、当社が設定します。

### 表示例

［**トーク**］タブの検索フォームに検索キーワードを入力し、［**ミニアプリ**］を選択した場合の表示例です。

![](/media/news/2026/mini-app-search-ja.webp){className="[\"bg-border\",\"w-fix-400\"]"}

| 行   | 表示内容              | 備考                                     |
| --- | ----------------- | -------------------------------------- |
| 1行目 | LINEミニアプリ名        |                                        |
| 2行目 | カテゴリ／LINEミニアプリの説明 | 文字数が多い場合は短縮して表示されます。情報が未設定の場合は表示されません。 |
| 3行目 | サービスバッジ           | 最大2件表示されます。未設定の場合は表示されません。             |

### 開発者の皆様へのお願い

今回の検索結果表示の仕様変更に際して、開発者側で追加の設定等をする必要はありません。

ただし、「カテゴリ」、「LINEミニアプリの説明」および「サービスバッジ」は、当該のLINEミニアプリチャネルの［**チャネル基本設定**］タブの［**チャネル説明**］の項目等に基づいて、当社が設定します。

そのため、［**チャネル説明**］の項目にはアプリの説明を具体的に分かりやすく入力してください。

詳しくは、『LINEミニアプリドキュメント』の「[チャネル説明の入力について](/docs/line-mini-app/discover/console-guide/#channel-description)」を参照してください。
