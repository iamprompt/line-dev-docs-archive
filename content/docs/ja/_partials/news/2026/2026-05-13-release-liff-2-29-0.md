::admonition{title="2026年10月20日追記" type="warning"}
ユーザーの安全を確保するため、2026年11月24日頃にLIFF SDKの旧バージョン（v2.20.0 〜 v2.31.0）の利用制限を実施する予定です。LIFF v2.29.0を利用している場合は、速やかにLIFF v2.31.1以降にアップデートしてください。詳しくは、2026年10月20日のニュース、「[LIFF/LINEミニアプリにおけるLIFF SDKの脆弱性の概要および旧バージョンの利用制限について](/news/2026/10/20/liff-sdk-issue/)」を参照してください。
::

::admonition{title="2026年9月30日追記" type="warning"}
LIFF v2.29.0は、セキュリティ上の影響が生じる可能性のある不具合が確認されたため、:glossary-tooltip[[非推奨](/glossary/#deprecated)]{glossary-id="deprecated"}となりました。LIFF v2.29.0を利用している場合は、LIFF v2.31.1以降にアップデートしてください。詳しくは、2026年9月30日のニュース、「[LIFF v2.31.1をリリースしました](/news/2026/09/30/release-liff-2-31-1/)」を参照してください。
::

LIFF v2.29.0をリリースしました。

LIFF v2.29.0では、LIFF SDK内部の挙動を変更しました。機能の変更はありません。

### LIFF v2.29.0へのアップデート方法

CDNエッジパス（`https://static.line-scdn.net/liff/edge/2/sdk.js`）を利用している場合は、自動でv2.29.0にアップデートされています。

npmパッケージを利用している場合は、`npm install @line/liff@2.29.0`もしくは`yarn add @line/liff@2.29.0`を実行するとv2.29.0にアップデートされます。

LIFF SDKの組み込み方法について詳しくは、『LIFFドキュメント』の「[LIFFアプリにLIFF SDKを組み込む](/docs/liff/developing-liff-apps/#integrating-sdk)」を参照してください。
