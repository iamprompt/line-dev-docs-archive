日本における[LINE API Expert](/community/#lae)、および[LINE API Platform Evangelist](/community/#platform-evangelist)の制度は、現在任命されているみなさまの任期をもって終了させていただくこととなりました。2027年以降は、日本において新規の任命および任命の更新は行われません。

なお台湾およびタイにおけるLINE API Expertの制度は、2027年以降も継続いたします。

### LINE API Expert制度の終了に寄せて

LINE API Expertは、LINE APIに対する深い理解、高い技術力、そしてコミュニティへの影響力を持つ開発者を任命する制度として、[2017年に始まりました](/news/2017/11/01/line-api-expert-release/)。また2026年初頭には、LINE API Expertの中でもコミュニティの運営と成長をリードする役割として、LINE API Platform Evangelistが新たに始まりました。

LINE API Expertは、まもなく10年という大きな節目を迎えます。この10年の間、日本においてLINE API Expertに任命されたみなさまは、400回を優に超えるさまざまなMeetupやハンズオンセミナーなど、活発なコミュニティ活動でLINE APIの普及に貢献してくださいました。こうした日々の活動は、LINE APIを全国へ広げていく大きな原動力となり、LINEプラットフォームを提供する私たちにとっても大きな支えとなりました。

これまでのみなさまのご貢献と、共に歩んだ日々に心からの敬意と感謝を申し上げます。

日本におけるLINE API Expert制度は終了しますが、開発者のみなさまがLINE APIを活用したサービスの開発をより円滑に進められるよう、今後もサービスの改善に取り組むとともに、LINE Developersサイトおよび開発者向けドキュメントの品質向上に努めてまいります。

これからもLINE APIを積極的にご活用いただき、みなさまによる革新的なサービスの創出にお役立ていただければ幸いです。
