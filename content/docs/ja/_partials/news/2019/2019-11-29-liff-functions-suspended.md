以下の機能は、技術的な問題があり提供を一時停止することになりました。今後の対応が決まり次第、改めてお知らせします。

- `liff.scanCode()`
- `liff.bluetooth.*`

## 一時停止バージョン

| LINE         | 一時停止バージョン                  |
| ------------ | -------------------------- |
| iOS版LINE     | 9.19.0以降は、上記の機能の提供を一時停止します |
| Android版LINE | 対応方法を検討しています               |
