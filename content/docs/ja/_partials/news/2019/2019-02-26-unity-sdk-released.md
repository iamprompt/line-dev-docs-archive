[LINE SDK 1.0.0 for Unity](/docs/unity-sdk/)がリリースされました。

LINE SDK for Unityは、既存の[LINE SDK for iOS](/docs/ios-sdk/)および[LINE SDK for Android](/docs/android-sdk/)のラッパーです。これらのSDKの機能を、Unityで開発されたゲームで利用できるようになりました。

詳しくは、『[LINE SDK for Unityドキュメント](/docs/unity-sdk/)』を参照してください。このガイドは、近日中に日本語化されます。

上記のガイドに加えて、SDKで利用できるメソッドのリファレンスもリリースする予定です。
