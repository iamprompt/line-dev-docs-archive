法人ユーザー向けオプションおよびLINE Ads Platform APIのドキュメントがリリースされました。

### 法人ユーザー向けオプション

法人ユーザー向けオプションのドキュメントでは、以下のオプション機能の使いかたを説明しています。

| オプション機能                                                | 概要                                                                       |
| ------------------------------------------------------ | ------------------------------------------------------------------------ |
| [エラー通知](/docs/partner-docs/error-notification/)        | LINEプラットフォームからボットサーバーにWebhookイベントを通知するときに問題が発生した場合に、チャネルの管理者にメールで通知できます。 |
| [ミッションスタンプ](/docs/partner-docs/mission-stickers/)      | ミッションの達成を条件としてユーザーにスタンプを提供することができます。                                     |
| [オーディエンスマッチ](/docs/partner-docs/audience-match/)       | ユーザーが保有するモバイル広告IDや、ユーザーの電話番号に基づいたターゲティング配信ができます。                         |
| [Mark-as-Read](/docs/partner-docs/mark-as-read/)       | 特定のユーザーから送信されたすべてのメッセージに、任意のタイミングで"既読"を表示できます。                           |
| [LINE Profile+](/docs/partner-docs/line-profile-plus/) | ユーザーがLINE Profile+に登録したユーザー情報（名前、性別、住所など）を、プロバイダーが提供するサービスで取得することができます。  |
| [LINE Beacon](/docs/partner-docs/line-beacon/)         | LINE Beaconを受信するための条件について説明します。                                          |

また、[法人ユーザー向けオプションAPIリファレンス](/reference/partner-docs/)も公開されています。

::admonition{title="オプション機能を利用するには手続きが必要です" type="note"}
法人ユーザー向けオプションのドキュメントに記載の機能は、所定の申請等を行った法人ユーザーのみがご利用いただけます。
自社のLINE公式アカウントでご利用になりたいお客様は、担当営業までご連絡いただくか、[弊社パートナー](https://www.linebiz.com/jp/partner/sales/){rel="[\"nofollow\"]"}にお問い合わせください。
::

### LINE Ads Platform API

LINE Ads Platform APIのドキュメントでは、LINE Ads Platformを利用している方に公開しているAPIの使いかたを説明しています。

詳しくは、以下のドキュメントを参照してください。

- [LINE Ads Platform APIドキュメント](/docs/line-ads-api/)（英語）
- [LINE Ads Platform APIリファレンス](/reference/line-ads-api/)（英語）

::admonition{title="LINE Ads Platform APIを利用するには手続きが必要です" type="note"}
LINE Ads Platform APIのドキュメントに記載の機能は、所定の申請等を行った法人ユーザーのみがご利用いただけます。
自社のLINE公式アカウントでご利用になりたいお客様は、担当営業までご連絡いただくか、[弊社パートナー](https://www.linebiz.com/jp/partner/sales/){rel="[\"nofollow\"]"}にお問い合わせください。
