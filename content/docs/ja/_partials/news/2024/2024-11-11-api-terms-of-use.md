2024年11月26日に、一部の国と地域における「LINE公式アカウントAPI利用規約」の改定を予定しています。

### 変更予定日

2024年11月26日

内容および日時は、予告なく変更される可能性があります。

### 変更内容

「LINE公式アカウントAPI利用規約」において、以下の改定を予定しています。

- 第7条を変更
- 改定前の第9条を削除

改定後の「LINE公式アカウントAPI利用規約」は以下のリンク先を参照してください。

| dummy      | dummy                                                                                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| タイ（TH）     | [ข้อกำหนดการใช้งานบัญชีทางการด้วยระบบเอพีไอ (LINE Official Account API Terms of Use)](https://terms2.line.me/official_account_api_terms_th?lang=th){rel="[\"nofollow\"]"} |
| 台湾（TW）     | [LINE Official Account API Terms of Use](https://terms2.line.me/official_account_api_terms_tw){rel="[\"nofollow\"]"}                                                      |
| その他（Other） | [LINE Official Account API Terms of Use](https://terms2.line.me/official_account_api_terms_oth){rel="[\"nofollow\"]"}                                                     |

なお日本（JP）の「[LINE公式アカウントAPI利用規約](https://terms2.line.me/official_account_api_terms_jp){rel="[\"nofollow\"]"}」では改定はございません。
