2020年3月31日に、**LINE Front-end Framework（LIFF） v1のサーバーAPI**の提供を終了します。提供終了日に、以下の機能を削除する予定です。

- [サーバーAPI](/reference/liff-server/)
  - [LIFFアプリをチャネルに追加する](/reference/liff-server/#add-liff-app)
  - [LIFFアプリの設定を更新する](/reference/liff-server/#update-liff-app)
  - [すべてのLIFFアプリを取得する](/reference/liff-server/#get-all-liff-apps)
  - [LIFFアプリをチャネルから削除する](/reference/liff-server/#delete-liff-app)

::admonition{title="最新バージョンのLIFFを使用してください" type="note"}
[2019年10月16日に告知](/news/2019/10/16/liff-v2-released/)したとおり、LIFF v1は、廃止される予定です。
::

### LIFF v2を利用してください

提供を終了するサーバーAPIの機能は、すべて[LINE Developersコンソール](/console/)で利用できます。LIFFアプリをチャネルに追加する操作について詳しくは、以下の項目を参照してください。

- [LIFFアプリをチャネルに追加する](/docs/liff/registering-liff-apps/)

そのほかの機能も、同様の操作で利用できます。

LINEは今後もお客様への一層のサービス向上に取組んでまいります。何卒ご理解を賜りますよう、よろしくお願い申し上げます。
