## ユーザー

::reference-with-code
  :::reference-content
  LINE公式アカウントを友だち追加したユーザーの情報を取得できます。

    ::::admonition{title="自分のユーザーIDを取得する" type="note"}
    自分のユーザーIDは、[LINE Developersコンソール](/console/)のチャネルの［**チャネル基本設定**］タブにある［**あなたのユーザーID**］で確認できます。LINE Developersコンソールのアクセス権限について詳しくは、『[権限を管理する](/docs/line-developers-console/managing-roles/)』の「[チャネルの権限](/docs/line-developers-console/managing-roles/#roles-for-channel)」を参照してください。開発者が自分自身のユーザーIDを取得するためのAPIはありません。
