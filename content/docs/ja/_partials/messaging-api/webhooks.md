## Webhook

友だち追加やユーザーからのメッセージ送信のようなイベントが発生すると、LINEプラットフォームからWebhook URL（ボットサーバー）にHTTPS POSTリクエストが送信されます。

Webhook URLはチャネルごとに[LINE Developersコンソール](/console/)で設定します。
